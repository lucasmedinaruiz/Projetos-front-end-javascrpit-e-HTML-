# Lista de Tarefas

Projeto de front-end com HTML, CSS e JavaScript puro.

## Funcionalidades
- Adicionar tarefas (botão ou tecla Enter)
- Marcar/desmarcar como feita (clique no texto)
- Remover tarefas
- Contador de tarefas pendentes

## Conceitos praticados
Manipulação do DOM, eventos, arrays (`push`, `splice`, `filter`, `forEach`) e funções.

## Como usar
Abra o arquivo `index.html` no navegador.
