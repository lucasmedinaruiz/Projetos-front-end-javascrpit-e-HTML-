# Calculadora de IMC

Projeto de front-end com HTML, CSS e JavaScript puro.

## Funcionalidades
- Calcula o IMC a partir de peso e altura
- Mostra a classificação (abaixo do peso, normal, sobrepeso, obesidade)
- Valida entradas vazias ou inválidas

## Conceitos praticados
Funções, condicionais (`if`), conversão de texto em número (`parseFloat`) e formatação (`toFixed`).

## Como usar
Abra o arquivo `index.html` no navegador.

> Projeto educacional, não substitui avaliação médica.
