# Conversor de Moedas

Projeto de front-end com HTML, CSS e JavaScript puro.

## Funcionalidades
- Converte reais para dólar, euro ou libra
- Usa um objeto JavaScript com cotações fixas (fictícias)

## Conceitos praticados
Objetos, `select` no HTML, leitura de campos, validação e formatação de números.

## Como usar
Abra o arquivo `index.html` no navegador.

## Melhoria futura
Buscar cotações reais de uma API com `fetch`.
